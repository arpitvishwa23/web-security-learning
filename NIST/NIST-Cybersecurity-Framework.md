# NIST Cybersecurity Framework (CSF)

This document contains my notes on the NIST Cybersecurity Framework (CSF).  
It is written in a simple way for better understanding of how cybersecurity is managed in organizations.

---

## What is NIST CSF?

The NIST Cybersecurity Framework is a set of guidelines created to help organizations manage and reduce cybersecurity risks.

It provides a structured way to understand, prevent, detect, and respond to cyber threats.

---

This is how the framework works in a cycle:

## Core Functions of NIST CSF

The framework is divided into 5 main functions:

---

## 1. Identify

This step is about understanding the system and risks.

### What it includes:
- Knowing what assets (hardware, software, data) you have
- Identifying risks and vulnerabilities
- Understanding business environment

### Simple meaning:
Before protecting anything, you must know what you are protecting.

---

## 2. Protect

This step focuses on applying security controls to safeguard systems.

### What it includes:
- Access control (who can access what)
- Data protection (encryption, backups)
- Security awareness training

### Simple meaning:
Put security measures in place to prevent attacks.

---

## 3. Detect

This step is about identifying security incidents when they happen.

### What it includes:
- Monitoring systems
- Intrusion detection systems
- Log analysis

### Simple meaning:
Find out quickly if something bad is happening.

---

## 4. Respond

This step deals with handling security incidents.

### What it includes:
- Incident response planning
- Communication during attack
- Mitigating damage

### Simple meaning:
Take action when an attack is detected.

---

## 5. Recover

This step is about restoring systems after an incident.

### What it includes:
- System restoration
- Data recovery from backups
- Improving systems after attack

### Simple meaning:
Get systems back to normal and learn from the incident.

---

## Summary

NIST CSF helps organizations:

- Understand their systems (Identify)
- Protect them from threats (Protect)
- Detect attacks (Detect)
- Respond to incidents (Respond)
- Recover from damage (Recover)
