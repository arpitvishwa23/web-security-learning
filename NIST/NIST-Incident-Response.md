# NIST Risk Management Framework (RMF)

This document contains my notes on the NIST Risk Management Framework (RMF).  
It explains how organizations manage security risks in information systems before they are deployed.

---

## What is RMF?

The Risk Management Framework (RMF) is a structured process used to identify, assess, and manage risks in an information system.

It ensures that security is properly planned, implemented, and monitored throughout the system lifecycle.

---

## RMF Steps

### 1. Prepare
Set up the risk management environment.

- Define roles and responsibilities  
- Create security policies  
- Understand system context  

---

### 2. Categorize
Define the impact level of the system.

- Low impact  
- Moderate impact  
- High impact  

---

### 3. Select
Choose security controls based on system needs.

- Access control  
- Encryption  
- Monitoring mechanisms  

---

### 4. Implement
Apply the selected security controls.

- Configure security settings  
- Deploy security tools  
- Enable logging and protection  

---

### 5. Assess
Check whether controls are working properly.

- Security testing  
- Vulnerability assessment  
- Compliance verification  

---

### 6. Authorize
Get official approval to operate the system.

- Risk acceptance decision  
- Management approval  

---

### 7. Monitor
Continuously observe system security.

- Log monitoring  
- Threat detection  
- Regular audits and updates  

---

## Simple Understanding

- Prepare → Plan everything  
- Categorize → Decide system risk level  
- Select → Choose security controls  
- Implement → Apply security measures  
- Assess → Test effectiveness  
- Authorize → Approve system  
- Monitor → Continuous tracking  

---

## My Understanding

RMF is a structured way to make sure systems are secure before and after deployment.

It helps organizations:
- Identify risks early  
- Apply proper security controls  
- Continuously monitor systems  

---

## Key Takeaway

RMF is not a one-time process.  
It is a continuous lifecycle used to manage risk throughout the system’s operation.
