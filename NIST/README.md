# NIST Cybersecurity Framework Notes

This contains my structured notes on important NIST cybersecurity concepts.  
It is created for learning purposes and to build a strong understanding of how cybersecurity is managed in real-world systems.

---

## What this covers

- NIST Cybersecurity Framework (CSF)
- NIST Risk Management Framework (RMF)
- NIST Incident Response Process

---

## Purpose

The main goal of this project is to understand:

- How organizations identify and manage cybersecurity risks  
- How security controls are selected and applied  
- How incidents are detected, handled, and recovered from  
- How structured frameworks improve cybersecurity governance
